Daily & Weekly Logs

Week 1 • June 15-19, 2026

Orientation, HTML, CSS & Git Bash

I started my OJT with a formal orientation covering the company culture, procedures, and internship requirements. I learned HTML foundations, semantic tags, document structure, and CSS basics including inline, internal, and external styling. I created a personal webpage and beginner exercises for text styling, buttons, boxes, and profile cards. I also designed a website for Mr. Seven using HTML and CSS, presented my progress, applied feedback, and learned Git Bash basics such as initializing repositories, checking project states, using git add, and using git commit.

Week 2 • June 22-25, 2026

JavaScript Foundations & Communication

I continued the daily routine of presenting IT-related news and receiving feedback to improve my communication and presentation skills. Through FreeCodeCamp, I studied JavaScript variables, strings, booleans, numbers, functions, arrays, objects, and loops. I also practiced typing tests to improve my speed and accuracy. The week strengthened my programming fundamentals, consistency, and confidence when presenting to co-interns and supervisors.

Week 3 • June 29-July 2, 2026

GitHub, Git & DOM Manipulation

I presented an IT news topic about Meta Ray-Ban Smart Glasses, discussing its built-in camera and AI capabilities. I continued developing the assigned website and practicing JavaScript, HTML, and CSS through FreeCodeCamp. I learned GitHub and Git for collaboration and version control, created a repository, and published the website online. I also received a task focused on JavaScript DOM Manipulation, exploring how JavaScript interacts with and modifies web page elements.

Week 4 • July 6-9, 2026

APIs, Docker & SQL Databases

I practiced touch typing, continued FreeCodeCamp lessons, studied the previous task's codebase, and researched topics for daily tech news presentations. I created a Todo List website using an API and applied POST, PUT, and DELETE methods. I also built a Docker container using a GitHub repository provided by Sir Rico as a guide and researched different SQL databases. By the end of the week, I rendered 43 hours and 30 minutes, with 114 hours and 35 minutes remaining.

Week 5 • July 13-16, 2026

Full-Stack Product Inventory System

I focused on developing a full-stack Product Inventory Management System. I created a development plan, built the backend, connected it to a local database, and tested API endpoints using Postman. I deployed the backend to Render, migrated the database to TiDB Cloud, and connected the frontend to the live backend API. The system includes registration, login, dashboard, product management, supplier management, transactions, and inventory management. After testing and fixing issues, I successfully deployed the system as a live web application.
